How to use Guess the Rating

The app looks at one blitz game and estimates how strong each player is, as a Lichess blitz rating range.

Estimate a game

  1. Open a finished blitz game on lichess.org and copy the address from the browser, for example https://lichess.org/bcRJNu4b. You can also paste the game's PGN instead.
  2. Paste it into the box on the Analyse page. No game at hand? Press one of the example buttons.
  3. Press Estimate ratings and wait a few seconds while Stockfish checks every move.
  4. For each player you see the estimate, the likely range, and the three things that moved the estimate most.
  5. Press Show real rating to compare the estimate with the rating in the game.

Reading the result

  • The big number is the model's best single estimate.
  • The green band on the bar is the range. The real rating falls inside it about 8 times in 10.
  • "Loss per move" (centipawns) measures how much worse a move was than Stockfish's choice. 100 centipawns is about one pawn. Stronger players lose fewer.
  • One game is a small sample. A player having a very good or very bad day will fool the model.

Which games work

  • Blitz only: 3 to 8 minutes per side, such as 3+0, 3+2, 5+0 or 5+3.
  • Standard chess, at least 10 moves by each side, with clock times. Lichess links always include clocks.
  • Games against computers and tournament berserk games are not supported.

When something goes wrong

  • "This is not a blitz game": the game used a bullet, rapid or classical clock.
  • "The PGN has no clock times": paste the Lichess link instead of the PGN.
  • "The model server is not answering": a new model may be loading. Try again in a minute.
  • "All analysis engines are busy": several people are using the app; try again shortly.

Pipeline page

The Pipeline page is for whoever runs the app. It shows each pipeline run with its stages, speed and log, the model versions and which one is serving, alerts, and live charts. Starting a run and rolling back to the previous model need the admin token from the .env file.

Privacy

Predictions are stored encrypted on the server for accuracy checks. Player names are not stored.
